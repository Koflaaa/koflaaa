Meine Ausbildung

Triale Ausbildung

Die Ausbildung am bfi IT-L@B Villach folgt der trialen Ausbildungsform, die eine Kombination aus Berufsschule, praxisorientierter Lehrwerkstätte (bfi IT-L@B) und praxisorientierter Partnerbetriebe in der Wirtschaft beinhaltet.

Die Lehrstelle

Das bfi IT-L@B startete im Jahr 2000 im Auftrag des Landes Kärnten und hat sich zu einem Erfolgsmodell entwickelt. An drei Standorten erhalten junge Erwachsene eine qualitativ hochwertige Ausbildung, die individuelle Stärken fördert. Theorie, Grundausbildung im bfi IT-L@B und Praxis in Unternehmen greifen ineinander. Neben Fachwissen werden soziale Kompetenzen wie Teamfähigkeit und Kundenorientierung vermittelt.

Programmierkenntnisse

Prozedural

Die 64-Aufgaben sollen einem Lehrling/einem Praktikanten Schritt für Schritt C# "beibringen" bzw. ihm die Syntax soweit näher bringen, dass man die "Logik" von C# versteht und selbstständig damit arbeiten kann.

Ausgabe eines „F“ mit Console.WriteLine(): 

#########
#
#
#
#######
#
#
#

Mögliche Lösung:

Console.WriteLine("#########");
Console.WriteLine("#");
Console.WriteLine("#");
Console.WriteLine("#");
Console.WriteLine("#######");
Console.WriteLine("#");
Console.WriteLine("#");
Console.WriteLine("#");

Oder kompakter:

Console.WriteLine("#########\n#\n#\n#\n#######\n#\n#\n#");

OOP

Ein Einstiegsbeispiel in die objektorientierte Programmierung wäre das Beispiel Fußball 1. Das Beispiel enthält ein Programm, das eine Mannschaft mit einem Sportchef, einem Trainer, zehn Feldspielern, drei Auswechselspielern und einem Torwart erstellt.

HTML

Meine erste Webseite in HTML ist eine Webseite für einen Blumenladen, auf der ca. 13 Bilder zu sehen sind. Die Bilder wurden alle von meinem Onkel gezeichnet und mir zur Verfügung gestellt.

JavaScript

Meine erste richtige Website mit JavaScript ist mein Web-Game. Es geht darum 22 Fragen zu den Themen Informatik und Programmieren zu beantworten. Hat man alle Fragen beantwortet, bekommt man eine Punktezahl zusammen mit einer Bewertung und einer Zeitangabe die in Sekunden ausgegeben wird. Insgesamt gibt es ca. 440 Punkte zu ergattern.

SQL

Meine erste SQL Aufgabe war es, eine Warenkorb-Datenbank in MSSQL zu erstellen. Die Aufgabe war es zuerst drei Tabellen zu erstellen, diese mit jeweils drei Datensätzen zu befüllen und anschließend ausgeben zu lassen. Zudem musste ich davor ein ER-Diagramm bzw. UML-Diagramm erstellen, damit ich gleich weiß, was ich wie verbinden muss und wie ich die Attribute und Methoden erstellen muss.

Python

Mein erstes Pythonprogramm habe ich durch Inspiration einer Kollegin erstellt. Mein Beispiel ist ein einfacher Taschenrechner, der die grundlegenden mathematischen Operationen ausführen kann. Gleichzeitig überprüft das Programm mit einer Abfrage, ob zahl1 oder zahl2 eine 0 ist. Wenn ja, wird eine Fehlermeldung ausgegeben, dass nicht durch 0 dividiert werden kann bzw. Divide Zero Error.

PHP

In meinem ersten PHP Script musste ich eine OOP Anwendung schreiben, die zwei Fußballmannschaften gegeneinander spielen lässt bzw. das Ergebnis/die Ergebnisse anzeigt, je nach den Attributen der Torwarte und Feldspieler. Es gibt je 2-3 Spieler und 1 Torwart pro Mannschaft. Anschließend, habe Ich ein HTML-Formular erstellt mit der man die Mannschaft auswählen kann, die zuerst spielen soll.
