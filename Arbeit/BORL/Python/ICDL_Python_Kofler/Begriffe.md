# Begriffe recherchieren + Beispiele
| **Begriff** | **Definition** | **Beispiel** |
| - | - | - |
| **Computing** | Computing ist der Überbegriff für das Rechnen mit Computern – einschließlich der Entwicklung, Nutzung und Analyse von Informationssystemen und Algorithmen. | Beispiel: Das Erstellen einer Website mit HTML, CSS und JavaScript. |
| **Computational Thinking** (Analytisches und logisches Denken) | Ist eine Denkweise in dem man wie ein Computer Mustererkennt, Zerlegung von Informationen, Abstrahieren von Informationen und das Erstellen von Algorithmen | Ein großes Problem (z. B. „Wie sortiere ich eine Liste?“) wird in kleinere Teilprobleme zerlegt (z. B. „Wie vergleiche ich zwei Elemente?“), daraus wird ein Algorithmus entwickelt, wie z. B. ein Sortierverfahren. |
| **Code** | Code ist die Gesamtheit der Anweisungen, die in einer Programmiersprache geschrieben wurden, damit ein Computer etwas ausführt. | print("Hello World") |
| **Quellcode** | Ist der ursprünglich geschriebene Code in z.B. JavaScript, Python oder Java | public class Hallo {public static void main(String[] args) {System.out.println("Hallo Welt");}} |
| **Maschinencode** | Maschinencode ist die niedrigste Ebene des Codes, bestehend aus binären Zahlen (0 und 1), den die Hardware direkt versteht. | Z.B. 10110000 01100001 |
| **Programm** | Ein Programm ist eine Sammlung von Anweisungen (Code), die zusammen eine bestimmte Aufgabe auf einem Computer ausführen. | Z.B. Microsoft Word oder ein Handy Taschenrechner |
| **Programmbeschreibung** | Eine allgemeine Erklärung zur Nutzung des Programm | Z.B. "Das Programm dient dazu, Zahlen zu addieren." |
| **Programmspezifizierung** | Die Programmspezifizierung ist eine präzise, technische Beschreibung der Anforderungen und Funktionen, die ein Programm erfüllen soll – meist vor der eigentlichen Entwicklung. | Eingaben: Gewicht in kg, Größe in Meter <br> Verarbeitung: BMI: Gewicht/(Größe^2) <br> BMI-Wert und Klassifikation nach WHO-Standards |
| **Natürliche Sprache** | Sprachen, die von Menschen zur alltäglichen Kommunikation verwendet werden. <br> Merkmale: Mehrdeutig, Unregelmäßigkeiten, Kontextabhängig, Emotional & kreativ | Deutsch, Englisch, Französisch |
| **Formele Sprache** | Künstlich definierte Sprache mit klaren, eindeutigen Regeln – oft in Mathematik, Logik oder Informatik verwendet. <br> Merkmale: Eindeutig & präzise, Streng regelbasiert, Nicht für Emotionale Kommunikationgedacht | Programmiersprachen (z. B. Python, Java), mathematische Formeln, reguläre Ausdrücke |
| **Problemkomposition** (Daten, Prozesse, komplexe Probleme) | Aufteilung eines komplexen Problems in kleinere, handhabbare Teilprobleme (Teilaufgaben). | z. B. „Wie sortiere ich eine Liste?“ wird in kleinere Teilprobleme zerlegt (z. B. „Wie vergleiche ich zwei Elemente?“), daraus wird ein Algorithmus entwickelt, wie z. B. ein Sortierverfahren. |
| **Mustererkennung** | Wiederkehrende Strukturen, Regeln oder Gemeinsamkeiten erkennen, um Probleme effizienter zu lösen. | Beim Sortieren von Wörtern erkennt man, dass viele mit demselben Buchstaben anfangen. |
| **Abstraktion** | Unwichtige Details weglassen, um sich auf das Wesentliche zu konzentrieren. | Ein Stadtplan zeigt Straßen und Gebäude, aber nicht Bäume oder Ampeln. |
| **Algorithmus** | Eine eindeutige Schritt-für-Schritt-Anleitung zur Lösung eines Problems. | Kochrezept oder: „Nimm eine Zahl, multipliziere mit 2, ziehe 3 ab.“ |
| **Sequenz** | Die feste Reihenfolge von Anweisungen, die nacheinander ausgeführt werden. | Beim Zähneputzen: 1. Zahnpasta auftragen → 2. Putzen → 3. Ausspülen. |
| **Ablaufdiagramm** (Flussdiagramm, Pseudocode) | Eine grafische oder textuelle Darstellung von Abläufen in einem Programm oder Prozess. | Flussdiagramm: Entscheidungsbaum zur Ampelsteuerung. <br> Pseudocode: „Wenn grün, dann gehen.“ |


| Programmentwicklung | Phasen | Zusatz |
| - | - | - |
| - |**Planung** | Definition des Problems, Zielsetzung, Auswahl der Programmiersprach |
| - |**Entwicklung** | Entwickeln des Programms, Testen und Debuggen |
| - |**Testen** | Überprüfung, ob das Programm die Anforderungen erfüll |
| - |**Veröffentlichung** | Freigabe des Programms für die Öffentlichkeit |
| - |**Wartung** | Aktualisierung und Pflege des Programms, um sicher |
