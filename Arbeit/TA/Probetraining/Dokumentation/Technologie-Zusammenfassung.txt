Backend – SQL, PSQL, MongoDB, Apache AGE, Apache Cassandra

🗄️ Backend-Datenbanken & Speicher

- SQL / PostgreSQL (PSQL)
  Relationale Datenbanken. Speichern strukturierte Daten in Tabellen mit festem Schema. Gut für komplexe Abfragen und Datenintegrität.
  Beispiel: Buchungssysteme, E-Commerce.

- MongoDB
  NoSQL-Datenbank. Speichert Daten als JSON-ähnliche Dokumente. Flexibel bei Schemaänderungen.
  Beispiel: Content-Management-Systeme, Apps mit unstrukturierten Daten.

- Apache AGE
  Erweiterung für PostgreSQL zur Verarbeitung von Graphdaten. Nutzt die Cypher-Abfragesprache (wie bei Neo4j).
  Beispiel: Soziale Netzwerke, Empfehlungs-Engines.

- Apache Cassandra
  Verteilte NoSQL-Datenbank. Hohe Skalierbarkeit und Verfügbarkeit. Speichert große Mengen an Daten über viele Server.
  Beispiel: Echtzeit-Analyse, IoT-Systeme.


🔁 Middleware – Apache Kafka, RabbitMQ

- Apache Kafka
  Verteiltes Event-Streaming-System. Ermöglicht Verarbeitung großer Datenströme in Echtzeit.
  Beispiel: Log-Verarbeitung, Datenpipelines.

- RabbitMQ
  Message-Queue-System. Verteilt Nachrichten zuverlässig zwischen Diensten über Warteschlangen.
  Beispiel: Auftragsverarbeitung, Microservices-Kommunikation.


🖥️ Frontend – IndexedDB, Session Storage, Cookies, JWT

- IndexedDB
  Browserinterne Datenbank für große Mengen strukturierter Daten. Asynchron und persistent.
  Beispiel: Offline-Webanwendungen, Caching.

- Session Storage
  Speichert Daten nur für die Dauer einer Browser-Sitzung. Schnell, aber flüchtig.
  Beispiel: Temporäre Formulareingaben.

- Cookies
  Kleine Datenstücke, die im Browser gespeichert werden. Werden mit jeder Anfrage an den Server gesendet.
  Beispiel: Sitzungsverwaltung, Nutzerverfolgung.

- JWT (JSON Web Token)
  Token-basierte Authentifizierung. Trägt codierte Nutzerdaten und Signatur zur Prüfung.
  Beispiel: Single Sign-On, API-Zugriffsschutz.
