--------------------Klauseln--------------------

1. WHERE
Wird verwendet, um die Auswahl der Datensätze zu filtern.
Beispiel:
    SELECT name, population FROM city WHERE name = 'Vienna';
    → Gibt nur Datensätze zurück, bei denen der Name „Vienna“ ist.

2. FROM
Gibt an, aus welcher Tabelle die Daten abgefragt werden.
Beispiel:
    SELECT name FROM city;
    → Holt alle name-Werte aus der Tabelle city.

3. DISTINCT
Verhindert, dass doppelte Werte in der Ergebnisliste angezeigt werden.
Beispiel:
    SELECT DISTINCT countrycode FROM city;
    → Gibt jeden countrycode nur einmal aus, auch wenn er mehrfach vorkommt.

4. ORDER BY
Sortiert die Ausgabe nach einer oder mehreren Spalten. Standard ist aufsteigend (ASC).
Beispiel:
    SELECT population FROM city ORDER BY population;
    → Gibt die Populationen von klein nach groß aus.

5. LIMIT
Begrenzt die Anzahl der zurückgegebenen Zeilen.
Beispiel:
    SELECT * FROM city LIMIT 5;
    → Gibt nur die ersten 5 Datensätze zurück.

--------------------Aggregatfunktionen--------------------

6. SUM
Berechnet die Summe eines Zahlenfeldes.
Beispiel:
    SELECT SUM(population) FROM city;
    → Gibt die gesamte Bevölkerung aller Städte zurück.

7. AVG
Berechnet den Durchschnittswert eines Zahlenfeldes.
Beispiel:
    SELECT AVG(population) FROM city;
    → Gibt die durchschnittliche Bevölkerungszahl zurück.

8. MIN
Gibt den kleinsten Wert eines Feldes zurück.
Beispiel:
    SELECT MIN(population) FROM city;
    → Gibt die kleinste Bevölkerungszahl zurück.

9. MAX
Gibt den größten Wert eines Feldes zurück.
Beispiel:
    SELECT MAX(population) FROM city;
    → Gibt die größte Bevölkerungszahl zurück.

10. COUNT
Zählt die Anzahl der Datensätze (oder Nicht-NULL-Werte in einer Spalte).
Beispiel:
    SELECT COUNT(*) FROM city;
    → Gibt die Anzahl aller Städte in der Tabelle zurück.

--------------------Logische Operatoren--------------------

11. AND
Kann verwendet werden um Filterkonditionen zu verbinden bzw. zu kombinieren.
Beispiel:
	SELECT * FROM city WHERE countrycode = 'AUT' AND district = 'Vienna';
	→ Gibt alle Datensätze aus die den countrycode 'AUT' und district = 'Vienna' haben.

12. OR
Wird verwendet, um mehrere Bedingungen zu verknüpfen, von denen mindestens eine erfüllt sein muss.
Beispiel:
	SELECT * FROM city WHERE countrycode = 'AUT' OR district = 'Vienna';
	→ Gibt alle Datensätze aus, die entweder den countrycode 'AUT' haben oder den district 'Vienna'.

13. NOT
Wird verwendet, um eine Bedingung auszuschließen.
Beispiel:
	SELECT * FROM city WHERE NOT district = 'Vienna'
	→ Gibt alle Datensätze zurück, bei denen der district nicht „Vienna“ ist.

------------------------- JOINs -------------------------

Was sind Joins?
Joins in SQL verbinden Daten aus zwei (oder mehr) Tabellen basierend auf einer gemeinsamen Spalte. Sie ermöglichen es, zusammengehörige Informationen aus mehreren Tabellen in einem Ergebnis darzustellen.

JOIN-Typen im Überblick (angenommen Schema: Tabelle A und Tabelle B mit einer gemeinsamen Spalte id):

14. INNER JOIN
Gibt nur Datensätze zurück, bei denen es in beiden Tabellen eine Übereinstimmung gibt.
Beispiel:
    SELECT * FROM A INNER JOIN B ON A.id = B.id;
→ Ergebnis: Nur A.id = B.id

15. LEFT JOIN (oder LEFT OUTER JOIN)
Gibt alle Datensätze aus der linken Tabelle A zurück – auch wenn es in B keine Übereinstimmung gibt. Fehlende Werte aus B werden als NULL angezeigt.
Beispiel:
    SELECT * FROM A LEFT JOIN B ON A.id = B.id;
→ Ergebnis: Alle A-Datensätze + passende B-Datensätze (sonst NULL)

16. RIGHT JOIN (oder RIGHT OUTER JOIN)
Gibt alle Datensätze aus der rechten Tabelle B zurück – auch wenn es in A keine Übereinstimmung gibt.
Beispiel:
    SELECT * FROM A RIGHT JOIN B ON A.id = B.id;
→ Ergebnis: Alle B-Datensätze + passende A-Datensätze (sonst NULL)
Hinweis: SQLite unterstützt RIGHT JOIN **nicht** direkt.

17. FULL JOIN (oder FULL OUTER JOIN)
Gibt alle Datensätze aus beiden Tabellen zurück. Bei fehlender Übereinstimmung wird jeweils NULL eingesetzt.
Beispiel:
    SELECT * FROM A FULL OUTER JOIN B ON A.id = B.id;
→ Ergebnis: Alle A- und B-Datensätze, egal ob passend oder nicht.
Hinweis: SQLite unterstützt FULL JOIN **nicht** direkt.

18. SELF JOIN
Verbindet eine Tabelle mit sich selbst – z.B. wenn man Hierarchien abbilden will.
Beispiel:
    SELECT A.name AS Person, B.name AS Vorgesetzter
    FROM mitarbeiter A
    JOIN mitarbeiter B ON A.vorgesetzter_id = B.id;
→ Ergebnis: Eine Liste von Personen mit ihren Vorgesetzten aus derselben Tabelle.	

Schematische Darstellung:

Tabelle A:                        Tabelle B:
+----+--------+                  +----+----------+
| id | name   |                  | id | beruf    |
+----+--------+                  +----+----------+
| 1  | Alice  |                  | 1  | Lehrerin |
| 2  | Bob    |                  | 2  | Arzt     |
| 3  | Carol  |                  | 4  | Pilot    |
+----+--------+                  +----+----------+

Ergebnisse:
- INNER JOIN: nur id = 1 und 2
- LEFT JOIN: id = 1, 2, 3 (Carol ohne Beruf)
- RIGHT JOIN: id = 1, 2, 4 (Pilot ohne Name)
- FULL JOIN: id = 1, 2, 3, 4


------------------------- Vergleichsoperatoren -------------------------

19. LIKE
Wird verwendet, um einem bestimmten Muster in einem Textfeld zu suchen.
Platzhalter:
	%: beliebige Anzahl an Zeichen
	_: genau ein Zeichen
Beispiel:
	SELECT * FROM city WHERE name LIKE 'V%'
	→ Gibt alle Städte zurück, deren Name mit "V" beginnt.


20. IN
Überprüft ob ein Wert in einer Liste von Werten enthalten ist.
Beispiel:
	SELECT * FROM city WHERE countrycode IN ('AUT', 'DEU', 'CHE', 'NL')
	→ Gibt alle Städte in Österreich, Deutschland oder der Niederlande aus.

21. BETWEEN
Überprüft ob ein Wert innerhalb eines bestimmten Berichs einhalten ist.
Beispiel:
	SELECT * FROM city WHERE population BETWEEN 100.000 AND 500.000
	→ Gibt alle Städte zurück, deren Population zwischen 100.000 und 500.000 liegt.
